# 回款统计统一命名

- 本期到账：到账日期落在所选期间内的全部有效收款，包含本期订单和历史订单。
- 本期回款：订单日期落在所选期间内的订单累计回款，包含之后月份收到的款。
- 本期回款率：本期回款 / 本期交易额。分母为零或数据缺失时不计算。

例如9月订单100元，已收20元；8月订单在9月到账30元：9月本期到账50元，本期回款20元，本期回款率20%。如9月订单于10月再收10元，则9月订单本期回款变为30元、回款率30%。

城市交易榜按本期交易额排序，附本期回款额和回款率；到账榜按本期到账排序。订单列表按订单日期范围展示本期回款；回款流水列表按到账日期范围展示本期到账。单笔记录的业务状态与原始接口字段未重命名。
