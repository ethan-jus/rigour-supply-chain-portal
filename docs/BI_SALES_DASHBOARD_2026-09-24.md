# 销售业绩看板实现与验收

## 当前行为

销售菜单直接进入团队业绩对比，点击姓名进入个人详情；连续滚动，返回保留排名筛选。沿用最终经营总览与城市看板的深色布局、完整元金额、亮绿色到账、金银铜牌及渐变目标进度。

- 年视图按月展示趋势，月视图使用1–7、8–14、15–21、22日至月底四段。选择年份进入全年，当前年度截至当前日期，上期为上年同期。
- 日视图查询北京时间完整一天，对比前一天。隐藏趋势、目标卡片、月度明细、排名目标与目标完成率；订单回款率仍保留。
- 四项目标：个人默认月交易40,000元、到账20,000元、新增合作200家、复购100家。正式配置逐月优先，缺失月份补默认值；年度累计12个月。客户实际数来自BI查询，并按期间去重。
- 离职且当前榜金额为0才隐藏；在职零金额保留，两榜分别筛选和排序。
- 个人详情包含客户统计与明细、品类/商品/型号筛选、月度金额明细、本期及全部历史订单回款率、本期到账来源拆分。

## 查询口径

本期交易额按订单日期；本期回款额为这些订单截至当前镜像的累计回款，包括后续月份到账。本期到账仅按付款日期，包含历史订单。本期回款率为本期回款额/本期订单额。全历史订单率不限制订单日期，仍受租户、授权、人员和城市筛选约束。

新增 `GET /api/v1/analytics/supply/dashboard/sales-analysis`，读取BI已有事实、HR员工投影、正式目标及商品分摊投影。人员排名由真实订单、真实到账及城市部门员工名单合并；不截取旧接口TopN后冒充完整排名。所有业务SQL先套授权CTE再聚合，商品与历史查询必须连接授权订单。拒绝全局商品分类，商品筛选只作用个人商品区域。

现有overview的到账序列使用收款经办人归属；本销售看板以新接口的订单所属销售到账序列替换，避免混用。未修改其他看板原有计算，本轮没有数据库迁移、同步触发或业务数据写入，复用现有同步投影。
