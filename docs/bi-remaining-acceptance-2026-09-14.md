# BI 剩余工作实施与验收

## 本轮落实

- 飞书在线只读采集与不可变证据复核：按本租户已绑定来源分页采集订单、明细和商品关联表，再由 BI 生成来源 / Order / BI 的复核版本。文件对账继续保留，在线失败不能退回旧文件冒充当前版本。
- 采集完整性、过滤范围、校验值和采集窗口由服务端保存、验证。分页完成不代表跨表原子快照，不能显示“实时已对平”。
- 采集成功而 BI 复核失败时，同一页面会话内可以重试已采集证据，不重复读取飞书，不导入订单。刷新页面后该内存重试入口不保留，证据仍保存在 Integration；尚未提供采集历史独立选择器。
- 补齐北京时间业务日：期间筛选、月度汇总、目标周期、比较期间及报表时间展示一致。计算保留原始精度，业务展示和 Excel 金额保持两位。
- 商品/分类排行保留未关联事实；ERP 商品目录与分类关联优先。未知商品组不计作新增商品，不传递伪商品主键。
- 窄屏指标调整为适应最小列宽，390px 下成本金额与单位保持一行。保留总览四项指标、成本和结余、样例标记及专题分析结构。
