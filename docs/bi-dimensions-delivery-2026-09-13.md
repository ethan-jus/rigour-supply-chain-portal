## 本轮已实现

| 业务问题 | 本轮处理 | 使用边界 |
| --- | --- | --- |
| 哪些销售比前期变化明显 | 两期销售/回款变化图，图上最多六人，明细保留全部可比人员 | 只连接两期均有记录的人员，不把前期缺记录写成零；单月时替代原先的大幅单点趋势图 |
| 目标差在哪里 | 城市、销售多指标目标矩阵，销售、回款、建联、合作分别计算；点击带入相应对象的目标配置范围 | 缺目标不显示 0%；部分月份目标标星及覆盖月份数；目标不等于 HR 工资结算 |
| 跨月目标是否算对 | 实际订单只统计同指标已配置月份与查询期间交集；移除 80 条目标截断 | 零目标、月份不完整目标不参与平均完成率；细分筛选不与完整目标混比；跨城销售不在单城视图与全域目标混比 |
| 商品品牌、分类、SKU 如何继续分析 | 删除分类/品牌切换后的重复图；商品明细统一进入城市商品报表，保留期间、城市、销售范围 | 维度来源维持现有 ERP 关联；不通过名称猜测未归属分类 |
| 城市商品销量与回款如何订货报批 | 金额/已归属回款/同单位订货数量切换；完整 SKU 分页与键盘核查；钻取返回；导出选定仓库库存及全仓采购发货附件 | 默认不分摊；混单回款仅手动分摊；无可靠仓库归属和单位换算时不推算城市库存或建议采购量 |
| 金额和空值会不会误导 | 多种金额图 tooltip 统一紧凑金额；采购价覆盖为零时估算成本显示缺失；部分覆盖仅显示已覆盖成本 | 金额原数值不变，明细/Excel保留两位小数；空库存不等于零库存 |
| 手机是否能读图 | 目标矩阵窄屏保留四项指标名、数值及部分月份标识 | 未完成全站 WCAG 审核，不以截图无溢出代替可访问性认证 |
