# 人事指标设置本地开发交接

更新于 2026-10-12。Web 与 Platform 均在 `feature/hr-target-settings`。上一轮代码已推送远程 dev；本次五项指标调整仅本地开发，未发布部署。

## 当前实现

- HR 是目标唯一维护方。`/api/v1/hr/target-settings` 读取和批量保存，`/history` 查询修改记录，`/values` 提供签名服务间有效值查询；BI 只读取有效值。
- 城市名单来自销售部下所有有效子部门；销售名单来自销售部及子部门员工档案。新增部门、员工随查询动态出现。
- 城市和个人统一五项：建联门店数、有效门店数、杨掌柜品牌销售额、销售总额、回款额。
- 建联口径为当月新增企微建联去重门店；有效口径为当月有有效订单的去重合作门店，包含新老客户。杨掌柜按用户确认的品牌全名“杨掌柜 X CBSA世界斯诺克学院”统计商品销售额；回款按实际到账日期统计。
- 三项新指标初始值为 0（不考核）；销售总额、回款额沿用 HR 原初始值及已保存值。旧 NEW_CUSTOMER/REPEAT_CUSTOMER 不再作为有效指标，历史记录保留原义。
- UI 保留月份、直接修改、批量修改、预览、原因和审计；没有默认/自定义选择器。城市和个人目标独立维护，不强制加总相等。
- 未新增目标表、未改写已执行迁移。五项继续使用 HR 现有目标表和修订事件表。
- 页面权限 `hr:targets:read`，修改权限 `hr:targets:write`；沿用 ALL/CUSTOM/DEPARTMENT/SELF 范围。服务间查询要求签名 SERVICE 身份及 `hr:targets:service-read`。
