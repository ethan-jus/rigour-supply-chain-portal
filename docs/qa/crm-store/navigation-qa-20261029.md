# 客户模块导航验收 · 2026-10-29

本记录描述本次本地版本，不作为后续页面设计约束。

## 变更

- 默认一级模块名称为“CRM”，侧栏标题为“客户关系管理”；保留租户自定义名称。
- 去掉“客户管理”折叠层，按“客户经营 / 基础资料”常显分组。
- 仅整理 IAM 已授权且可见的入口，保留路由、权限、自定义名称、图标和组内顺序。有效入口只有一组时隐藏分组标题。
- 二级导航统一浅色背景、图标对齐、当前页标识、悬停与键盘焦点；其他模块需要的层级菜单继续折叠展示。

## 验证

- 6 个相关测试文件，28 项测试通过：客户导航、控制台首页、工作区标签、菜单自定义、人事导航、成本导航。
- `pnpm typecheck`、4 个变更文件的 ESLint、`pnpm build` 通过。构建存在既有大分包提示。
- Chrome localhost:5100 真实页面：客户 / 公海 / 我的客户 / 合作客户切换与选中状态正常；客户模块无折叠分组；ERP 商品中心仍可展开子入口。
- 1440 × 900：页面无横向溢出，键盘 Tab 焦点有可见边框。
- 390 × 844：侧栏默认收起，展开宽度 220px、起点 x=64px，全部 10 个客户入口可见；选择入口后自动收起，无页面横向溢出。验收后已恢复原始视口。
- 接口曾短暂提示服务不可用，之后公海恢复显示 11 条 DEV 数据。本次只验收导航，不据此声明业务全链路验收完成。

## 命名与样式精修

- 按用户后续确认采用 CRM / 客户关系管理，分组标题加重并调整与菜单的间距，标题与分组对齐；选中条缩为内嵌细线。
- 精修后客户导航、工作区标签、菜单自定义、客户地域权限 4 个文件共 19 项测试通过；类型检查、定向 ESLint 和格式检查通过。
- Chrome 真实页面已验证 CRM 名称、客户关系管理标题、两个常显分组及公海选中状态。
- 行政区划现有入口：系统设置 → 客户地域权限 → 行政区划目录。页面实测展示版本 `DEV_CRM_20261028`，仅为杭州、兰州联调样本，不能视为全国正式行政目录。
- 行政树及版本由 Foundation 的 `admin_division` / `admin_division_version` 管理，七大区域为 `GEO_REGION` 字典。部门地域范围由 IAM 的 `department_admin_scope` 管理。本轮未变更这些数据、权限或旧客户映射。
