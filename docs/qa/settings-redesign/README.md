# 行政区划与数据字典改版验收

日期：2026-10-29。本地服务 localhost:5100；使用已有登录会话和真实业务接口。

## 设计选择

以 ui-ux-pro-max 为主，design-taste-frontend 的 app-screen / framed-sheet 指导结构，frontend-design 校核内容层次。保留 Vue、Element Plus、现有蓝色品牌和应用外壳。

- 工作目标：行政区划快速定位地区及官方父子层级；数据字典快速找到业务选项并维护。
- 选择目录与内容分栏，而不是继续堆叠宽列表和详情抽屉。行政目录按真实七大区域分组；字典目录以业务名称为主、编码为辅。
- 色彩：文字 #0f172a，正文 #334155，辅助 #64748b，选中与操作 #2563eb，底色 #f8fafc，内容 #ffffff。边界沿用项目 #e2e8f0。
- 字体沿用中文系统字体；24px 页面标题、18px 内容标题、14px 业务名称、12px 编码与辅助信息。编码才使用 code 字体。
- 页面 24/28px 留白，目录 220/256px，白色工作区 12px 圆角，无装饰阴影。蓝色用于选中位置和主要操作。
- 手机/平板窄屏将目录替换为选择器，宽数据表独立横向滚动。全页不横向溢出。

结构：

```text
页面标题 + 简短用途                                  刷新 / 新增
[行政区划：省级、地级、县级总数与目录版本]
┌─────────────┬────────────────────────────────────┐
│ 地区/字典目录 │ 当前对象名称 + 编码               编辑 │
│ 搜索或大区分组│ 标签页 / 条件搜索                     │
│ 选中项       │ 名称与编码 / 等级或状态 / 业务说明       │
│              │ 数据表                               │
│              │ 结果数量                             │
└─────────────┴────────────────────────────────────┘
```

## 行为变更

- 行政区划保留官方树、搜索分页、版本和来源说明；选择省份查看直属地区，选择大区查看省份；不虚构直辖市中间节点。只有省级资料的地区给出准确空状态。
- 字典目录支持名称与编码搜索。选中即显示标准项、历史兼容和来源映射。
- 删除整目录明细预取。初次加载只请求目录和首个字典明细，避免原先 114 个明细请求。
- 请求序号防止快速切换时旧请求覆盖当前内容。失败状态区别于空数据，提供重新加载。
- 窄屏选择器规范化数字 ID 的比较；实际接口返回数字 ID 的情况已覆盖回归测试。
- 编辑、权限、版本号、固定字典限制、合并预览及业务字典刷新机制保留。实际页面验收未提交新增、修改、合并或扫描操作。
