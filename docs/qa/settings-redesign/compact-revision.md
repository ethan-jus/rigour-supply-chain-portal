# 紧凑列表与系统字体修订（当前版本）

2026-10-29。此记录取代 README.md 中第一版的排版规范。

## 修订依据

用户指出第一版标题、描述、统计层层堆叠，名称/编码双行浪费高度，名称列在大屏过度拉伸，表头和目录颜色太浅。双行目录式排版属于之前的设计选择，不是业务要求；本轮采用用户提供的商业后台参考，优先可读性与工作密度。

- 删除两个页面的常驻描述、行政区划统计行与重复层级说明。来源、目录版本、总量放入“数据来源”；字典说明放入说明按钮。
- 行政区划当前范围与查询控件同一行；字典的名称、编码、来源和编辑操作同一行，标签与搜索同一工具栏。
- 地区名称与行政编码、字典项名称与编码均为独立列，单行 40px；行政名称列固定 190px，编码 120px，不随大屏无限扩张。
- 目录使用单行、深色文字，蓝色选中态。字典仍可按名称或编码搜索，编码保留在详情和悬停标题中。

## 系统公共字体入口

`src/assets/styles/_typography.scss` 定义全站字体族、字号、文字色、Element Plus 字体映射和通用表头样式；字号与文字颜色的基础值继续来自 `_variables.scss`。`_reset.scss`、`_supply-chain.scss`、两个页面都引用公共语义值。未新增用户偏好设置页面。

- 字体：PingFang SC → Microsoft YaHei → Arial → sans-serif。
- 正文与标准表格：14px；辅助文字 13px；标签 12px；页面标题 18px。
- 表头：14px / 600 / #1f2329；正文 #303133；辅助 #606266。
- 公共主题优先级覆盖 Element Plus 延迟加载的默认变量，避免延迟加载后恢复为浅灰表头。
- 用户管理页实测正文、输入框、表格继承同一字体；表头 14px、#1f2329，页面横向溢出 0。

## 验证

- 25 项相关测试通过（行政区划、字典组件、契约页面、字典治理、设置导航、CRM 导航）。
- vue-tsc、ESLint、生产构建通过。构建仍有原有大 chunk 提示。
- 1366×768 行政区划表格从 Y=183 开始，行高 40px，数据视口高 494px，完整可见 12 行。
- 1280×720 字典详情表高 445px，10 个商品单位均可见；表格与全页均无水平溢出。
- 实际接口查询 330105 返回拱墅区，行政路径为浙江省 / 杭州市 / 拱墅区；字典目录和标准项读取正常。
- 本轮没有提交业务数据写入。
